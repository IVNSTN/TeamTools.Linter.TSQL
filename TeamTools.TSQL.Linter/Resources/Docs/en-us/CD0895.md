
# ANSI_NULLS or QUOTED_IDENTIFIERS is defined inside object definition

|||
|-|-|
| Id | **CD0895**
| Mnemo | CREATE_OPTIONS_INSIDE
| Severity | ℹ Hint
| Category | [ContinuousDelivery](./Category_ContinuousDelivery.md)
| Source code | [CreateOptionsInsideRule.cs](../../../Rules/ContinuousDeployment/CreateOptionsInsideRule.cs)

## Cause

This rule is triggered when `ANSI_NULLS` or `QUOTED_IDENTIFIERS` is defined inside an object.
<p id="descr">Move ANSI_NULLS or QUOTED_IDENTIFIERS before the CREATE statement.</p>

## Examples

Bad

```sql
CREATE PROCEDURE dbo.foo
AS
BEGIN
    SET QUOTED_IDENTIFIER, ANSI_NULLS ON;
END;
GO
```

Good

```sql
SET ANSI_NULLS, QUOTED_IDENTIFIER ON;
GO

CREATE PROCEDURE dbo.foo
AS
;
GO
```
