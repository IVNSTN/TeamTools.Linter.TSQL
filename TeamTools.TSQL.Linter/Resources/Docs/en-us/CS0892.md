

# Casting XML directly to string with escaped service characters

|||
|-|-|
| Id | **CS0892**
| Mnemo | CAST_XML_TO_STRING
| Severity | ℹ Hint
| Category | [CodeSmell](./Category_CodeSmell.md)
| Source code | [CastXmlToStringRule.cs](../../../Rules/CodeSmell/CastXmlToStringRule.cs)

## Cause

This rule is triggered when XML is converted to string with escaped service characters.
<p id="descr">Use .value('.', 'NVARCHAR(MAX)') or STRING_AGG.</p>

## Examples

Bad

```sql
SELECT STUFF(CAST((
                      SELECT ', ' + v.name
                      FROM (VALUES ('bonnie & clyde'), ('thelma & louise')) AS v (name)
                      FOR XML PATH(''), TYPE
                  ) AS NVARCHAR(MAX))
             , 1, 2, ''
            );
```

Good

```sql
SELECT STUFF((
                 SELECT ', ' + v.name
                 FROM (VALUES ('bonnie & clyde'), ('thelma & louise')) AS v (name)
                 FOR XML PATH(''), TYPE
             ).value('.', 'NVARCHAR(MAX)')
             , 1, 2, ''
            );
```
