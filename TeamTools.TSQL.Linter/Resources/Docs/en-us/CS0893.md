

# Jumping between isolation levels

|||
|-|-|
| Id | **CS0893**
| Mnemo | ISOLATION_CONTRADICTION
| Severity | ℹ Hint
| Category | [CodeSmell](./Category_CodeSmell.md)
| Source code | [IsolationLevelContradictionRule.cs](../../../Rules/CodeSmell/IsolationLevelContradictionRule.cs)

## Cause

This rule is triggered when the isolation level set via hint differs sharply from `SET TRANSACTION ISOLATION LEVEL`.
<p id="descr">Remove sharp change of isolation level.</p>

## Examples

Bad

```sql
SET TRANSACTION ISOLATION LEVEL REPEATABLE READ;

-- downgrade
SELECT * FROM tbl WITH (NOLOCK);
GO

SET TRANSACTION ISOLATION LEVEL READ COMMITTED;

-- upgrate
SELECT * FROM tbl WITH (SERIALIZABLE);
GO
```
