
# Options are enumerated not alphabetically

|||
|-|-|
| Id | **CV0897**
| Mnemo | SET_OPTIONS_ASC_ORDER
| Severity | ℹ Hint
| Category | [CodingConvention](./Category_CodingConvention.md)
| Source code | [SetOptionsInAscOrderRule.cs](../../../Rules/CodingConvention/SetOptionsInAscOrderRule.cs)

## Cause

This rule is triggered when options are enumerated not in alphabetical order.
<p id="descr">Specify options in alphabetical order.</p>

## Examples

Bad

```sql
SET XACT_ABORT, ANSI_NULLS, NOCOUNT ON;
```

Good

```sql
SET ANSI_NULLS, NOCOUNT, XACT_ABORT ON;
```
