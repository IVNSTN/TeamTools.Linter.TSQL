
# Unresolved window name reference

|||
|-|-|
| Id | **FA0451**
| Mnemo | UNRESOLVED_WINDOW_NAME
| Severity | ⛔ Error
| Category | [Failure](./Category_Failure.md)
| Source code | [UnresolvedWindowNameRule.cs](../../../Rules/Failure/UnresolvedWindowNameRule.cs)

## Cause

This rule is triggered when a window name specified in `SELECT` does not exist in the `WINDOW` clause.
<p id="descr">Fix the window name.</p>

## Examples

Bad

```sql
SELECT
    ProductID
    , SUM(OrderQty) OVER foo AS Total
FROM Sales.SalesOrderDetail
WINDOW bar AS(PARTITION BY SalesOrderID);
```

Good

```sql
SELECT
    ProductID
    , SUM(OrderQty) OVER bar AS Total
FROM Sales.SalesOrderDetail
WINDOW bar AS(PARTITION BY SalesOrderID);
```
