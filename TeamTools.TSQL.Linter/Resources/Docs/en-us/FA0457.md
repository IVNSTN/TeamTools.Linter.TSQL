
# Variable is redeclared

|||
|-|-|
| Id | **FA0457**
| Mnemo | VARIABLE_REDECLARED
| Severity | ⛔ Error
| Category | [Failure](./Category_Failure.md)
| Source code | [VariableRedeclaredRule.cs](../../../Rules/Failure/VariableRedeclaredRule.cs)

## Cause

This rule is triggered when a variable is declared more than once.
<p id="descr">Remove the duplicate variable declaration.</p>

## Examples

Bad

```sql
DECLARE @var INT = 1
-- ...
DECLARE @var DATE = GETDATE()
```
