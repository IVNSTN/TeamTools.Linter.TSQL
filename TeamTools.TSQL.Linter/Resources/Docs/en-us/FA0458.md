
# Unresolved scalar variable reference

|||
|-|-|
| Id | **FA0458**
| Mnemo | UNRESOLVED_VARIABLED_NAME
| Severity | ⛔ Error
| Category | [Failure](./Category_Failure.md)
| Source code | [UnresolvedVariableReferenceRule.cs](../../../Rules/Failure/UnresolvedVariableReferenceRule.cs)

## Cause

This rule is triggered when a scalar variable is used but not declared earlier in the code.
<p id="descr">Declare the scalar variable.</p>

## Examples

Bad

```sql
SELECT name
FROM dbo.users
WHERE id = @user_id;
```

Good

```sql
DECLARE @user_id INT = 5;

SELECT name
FROM dbo.users
WHERE id = @user_id
```
