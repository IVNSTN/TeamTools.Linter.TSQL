
# Unresolved table variable reference

|||
|-|-|
| Id | **FA0459**
| Mnemo | UNRESOLVED_TABLE_VAR_NAME
| Severity | ⛔ Error
| Category | [Failure](./Category_Failure.md)
| Source code | [UnresolvedTableVariableReferenceRule.cs](../../../Rules/Failure/UnresolvedTableVariableReferenceRule.cs)

## Cause

This rule is triggered when a table variable is used but not declared earlier in the code.
<p id="descr">Declare the table variable.</p>

## Examples

Bad

```sql
SELECT usr.name
FROM dbo.users AS usr
INNER JOIN @ids AS ids
    ON ids.id = usr.id;
```

Good

```sql
DECLARE @ids TABLE (id INT PRIMARY KEY);
-- ...
SELECT usr.name
FROM dbo.users AS usr
INNER JOIN @ids AS ids
    ON ids.id = usr.id;
```
