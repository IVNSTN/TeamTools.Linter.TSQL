

# Foreign key columns are not indexed

|||
|-|-|
| Id | **PF0867**
| Mnemo | INDEX_FK
| Severity | ℹ Hint
| Category | [Performance](./Category_Performance.md)
| Source code | [ForeignKeyIndexRule.cs](../../../Rules/Performance/ForeignKeyIndexRule.cs)

## Cause

This rule is triggered when foreign key columns are not indexed.
<p id="descr">Index the foreign key columns.</p>

## Examples

Bad

```sql
CREATE TABLE dbo.foo
(
    id           INT NOT NULL
    , group_id   INT NOT NULL
    , CONSTRAINT FK_group_id FOREIGN KEY (group_id) REFERENCES dbo.foo_groups (id)
);
GO
```

Good

```sql
CREATE TABLE dbo.foo
(
    id           INT NOT NULL
    , group_id   INT NOT NULL
    , CONSTRAINT FK_group_id FOREIGN KEY (group_id) REFERENCES dbo.foo_groups (id)
);
GO

CREATE NONCLUSTERED INDEX IX_group_id
    ON dbo.foo (group_id);
GO
```
