

# Serial plan is forced manually

|||
|-|-|
| Id | **PF0872**
| Mnemo | SERIAL_PLAN_FORCED
| Severity | ℹ Hint
| Category | [Performance](./Category_Performance.md)
| Source code | [SerialPlanForcedRule.cs](../../../Rules/Performance/SerialPlanForcedRule.cs)

## Cause

This rule is triggered when `MAXDOP 1`, `REMOTE` join or `OUTPUT` without `INTO` is specified in the query.
<p id="descr">Remove MAXDOP 1, REMOTE join or OUTPUT without INTO.</p>

## Examples

Bad

```sql
INSERT INTO dbo.foo (title)
OUTPUT INSERTED.id
SELECT title
FROM dbo.bar;
GO

SELECT f.title
FROM dbo.foo AS f
INNER REMOTE JOIN dbo.bar AS b
    ON f.id = b.parent_id
OPTION (MAXDOP 1);
GO
```

Good

```sql
INSERT dbo.foo (title)
OUTPUT INSERTED.id
INTO @ids
SELECT title
FROM dbo.bar;
GO

SELECT f.title
FROM dbo.foo AS f
INNER JOIN dbo.bar AS b
    ON f.id = b.parent_id;
GO
```
