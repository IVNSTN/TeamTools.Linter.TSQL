

# Serial plan is forced because of table variable modification

|||
|-|-|
| Id | **PF0873**
| Mnemo | SERIAL_PLAN_FORCED_TABLE_VAR
| Severity | ℹ Hint
| Category | [Performance](./Category_Performance.md)
| Source code | [SerialPlanForcedByTableVariableRule.cs](../../../Rules/Performance/SerialPlanForcedByTableVariableRule.cs)

## Cause

This rule is triggered when table variable is modified in the query.
<p id="descr">Replace the table variable with a temporary table.</p>

## Examples

Bad

```sql
INSERT INTO @var_table(title)
SELECT title
FROM bar;
```

Good

```sql
INSERT INTO #temp_table(title)
SELECT title
FROM bar;
```
