

# Serial plan zone is forced by instruction

|||
|-|-|
| Id | **PF0874**
| Mnemo | SERIAL_PLAN_ZONE_FORCED
| Severity | ℹ Hint
| Category | [Performance](./Category_Performance.md)
| Source code | [SerialPlanZoneForcedRule.cs](../../../Rules/Performance/SerialPlanZoneForcedRule.cs)

## Cause

This rule is triggered when instructions that lead to a serial plan zone is used in the query.
<p id="descr">Change the logic or remove instructions that lead to a serial plan zone.</p>

## Examples

Bad

```sql
INSERT INTO @var_table(title)
SELECT title
FROM bar;
```

Good

```sql
INSERT INTO #temp_table(title)
SELECT title
FROM bar;
```
