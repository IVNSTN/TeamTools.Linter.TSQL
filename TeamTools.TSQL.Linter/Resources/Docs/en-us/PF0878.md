

# Single-user mode zone is forced by instruction

|||
|-|-|
| Id | **PF0878**
| Mnemo | SINGLE_USER_MODE_ZONE_FORCED
| Severity | ℹ Hint
| Category | [Performance](./Category_Performance.md)
| Source code | [SingleUserModeZoneForcedRule.cs](../../../Rules/Performance/SingleUserModeZoneForcedRule.cs)

## Cause

This rule is triggered when `sp_getapplock` or hints: `TABLOCKX`, `TABLOCK+XLOCK`, `TABLOCK+UPDLOCK` is used in code.
<p id="descr">Remove sp_getapplock or hints: TABLOCKX, TABLOCK+XLOCK, TABLOCK+UPDLOCK.</p>

## Examples

Bad

```sql
SELECT id
FROM dbo.foo WITH (TABLOCKX);

DELETE dbo.foo
WHERE id < 5
OPTION (TABLE HINT(TABLOCK, UPDLOCK));
```

Good

```sql
SELECT id
FROM dbo.foo;

DELETE dbo.foo
WHERE id < 5;
```
