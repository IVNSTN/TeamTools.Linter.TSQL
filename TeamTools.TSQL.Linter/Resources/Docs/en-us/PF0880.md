

# JOIN predicate is missing straight equality filter

|||
|-|-|
| Id | **PF0880**
| Mnemo | NO_EQUALITY_FILTER_JOIN
| Severity | ℹ Hint
| Category | [Performance](./Category_Performance.md)
| Source code | [NoEqualityFilterInJoinRule.cs](../../../Rules/Performance/NoEqualityFilterInJoinRule.cs)

## Cause

This rule is triggered when `JOIN` predicate is missing straight equality filter.
<p id="descr"Add straight equality filter.</p>

## Examples

Bad

```sql
SELECT f.id
FROM dbo.foo AS f
INNER JOIN dbo.bar AS b
    ON f.date > y.date;
```

Good

```sql
SELECT f.id
FROM dbo.foo AS f
INNER JOIN dbo.bar AS b
    ON f.date = y.date;
```
