

# WHERE predicate is missing straight equality filter

|||
|-|-|
| Id | **PF0881**
| Mnemo | NO_EQUALITY_FILTER_WHERE
| Severity | ℹ Hint
| Category | [Performance](./Category_Performance.md)
| Source code | [NoEqualityFilterInWhereRule.cs](../../../Rules/Performance/NoEqualityFilterInWhereRule.cs)

## Cause

This rule is triggered when `WHERE` predicate is missing straight equality filter.
<p id="descr">Add straight equality filter.</p>

## Examples

Bad

```sql
SELECT f.id
FROM dbo.foo AS f
INNER JOIN dbo.bar AS b
    ON f.date = y.date
WHERE f.date > @year_begin;
```

Good

```sql
SELECT f.id
FROM dbo.foo AS f
INNER JOIN dbo.bar AS b
    ON f.date = y.date
WHERE f.date_year = @year;
```
