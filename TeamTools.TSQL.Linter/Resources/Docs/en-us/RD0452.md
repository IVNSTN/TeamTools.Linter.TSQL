
# Redundant window clause definition

|||
|-|-|
| Id | **RD0452**
| Mnemo | UNUSED_WINDOW_CLAUSE
| Severity | ⚠ Warning
| Category | [Redundancy](./Category_Redundancy.md)
| Source code | [UnusedWindowClauseRule.cs](../../../Rules/Redundancy/UnusedWindowClauseRule.cs)

## Cause

This rule is triggered when a window is declared in the `WINDOW` clause but never used.
<p id="descr">Remove the redundant window.</p>

## Examples

Bad

```sql
SELECT
    ProductID
FROM Sales.SalesOrderDetail
WINDOW bar AS(PARTITION BY SalesOrderID);
```

Good

```sql
SELECT
    ProductID
FROM Sales.SalesOrderDetail;
```
