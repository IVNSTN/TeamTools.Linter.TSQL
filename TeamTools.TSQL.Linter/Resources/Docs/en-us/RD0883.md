

# Redundant ISNULL computation for inequality comparison

|||
|-|-|
| Id | **RD0883**
| Mnemo | REDUNDANT_ISNULL_NOT_EQUALS
| Severity | ℹ Hint
| Category | [Redundancy](./Category_Redundancy.md)
| Source code | [RedundantIsNullForInequalityRule.cs](../../../Rules/Redundancy/RedundantIsNullForInequalityRule.cs)

## Cause

This rule is triggered when the expression loses its meaning if returning `replacement_value` in `ISNULL`.
<p id="descr">Remove redundant ISNULL.</p>

## Examples

Bad

```sql
SELECT * 
FROM foo 
WHERE foo.col <> ISNULL(@arg, foo.col);
```

Good

```sql
SELECT * 
FROM foo 
WHERE foo.col <> @arg;
```
