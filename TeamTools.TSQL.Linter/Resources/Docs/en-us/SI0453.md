
# Window clause definition can be reused

|||
|-|-|
| Id | **SI0453**
| Mnemo | EXTRACT_WINDOW_CLAUSE
| Severity | ℹ Hint
| Category | [Simplification](./Category_Simplification.md)
| Source code | [ExtractWindowClauseRule.cs](../../../Rules/Simplification/ExtractWindowClauseRule.cs)

## Cause

This rule is triggered when identical window definitions are detected.
<p id="descr">Extract window definitions into the WINDOW clause.</p>

## Examples

Bad

```sql
SELECT 
    ProductID
    , SUM(OrderQty) OVER (PARTITION BY SalesOrderID ROWS BETWEEN 2 PRECEDING AND 3 FOLLOWING) AS Total
    , AVG(OrderQty) OVER (PARTITION BY SalesOrderID ROWS BETWEEN 2 PRECEDING AND 3 FOLLOWING) AS Avg
FROM Sales.SalesOrderDetail;
```

Good

```sql
SELECT 
    ProductID
    , SUM(OrderQty) OVER win AS Total
    , AVG(OrderQty) OVER win AS Avg
FROM Sales.SalesOrderDetail
WINDOW win AS (PARTITION BY SalesOrderID ROWS BETWEEN 2 PRECEDING AND 3 FOLLOWING);
```
