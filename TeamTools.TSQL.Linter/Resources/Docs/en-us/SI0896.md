
# SET option statements can be combined

|||
|-|-|
| Id | **SI0896**
| Mnemo | MULTIPLE_SET_INTO_ONE
| Severity | ℹ Hint
| Category | [Simplification](./Category_Simplification.md)
| Source code | [MultipleSetOptionIntoOneRule.cs](../../../Rules/Simplification/MultipleSetOptionIntoOneRule.cs)

## Cause

This rule is triggered when SET option statements are defined separately.
<p id="descr">Combine SET option statements.</p>

## Examples

Bad

```sql
SET NOCOUNT ON;
SET XACT_ABORT ON;
```

Good

```sql
SET NOCOUNT, XACT_ABORT ON;
```
