

# Attempt to output a secret

|||
|-|-|
| Id | **VU0525**
| Mnemo | OUTPUT_SECRET
| Severity | ℹ Hint
| Category | [Vulnerability](./Category_Vulnerability.md)
| Source code | [OutputSecretRule.cs](../../../Rules/Vulnerability/OutputSecretRule.cs)

## Cause

This rule is triggered when an attempt is made to return a secret via the `SELECT` or `OUTPUT` parameters.
<p id="descr">Remove the code that returns the secret.</p>

## Examples

Bad

```sql
SELECT password FROM dbo.users;
```

## Tips

💡 This rule checks columns and parameters with names:

- password
- pass_word
- pwd
- pswd
- secret
