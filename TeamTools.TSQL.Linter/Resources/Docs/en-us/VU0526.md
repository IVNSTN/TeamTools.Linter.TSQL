

# Reading system data about security subjects or objects

|||
|-|-|
| Id | **VU0526**
| Mnemo | READ_SECRET
| Severity | ℹ Hint
| Category | [Vulnerability](./Category_Vulnerability.md)
| Source code | [ReadingSecretDataRule.cs](../../../Rules/Vulnerability/ReadingSecretDataRule.cs)

## Cause

This rule is triggered when an attempt is made to read system data about security subjects or objects.
<p id="descr">Remove reading system data about security subjects or objects.</p>

## Examples

Bad

```sql
SELECT * FROM sys.database_credentials;
```

## Tips

💡 This rule checks reading from:

- sys.credentials
- sys.database_credentials
- sys.database_permissions
- sys.database_principals
- sys.database_role_members
- sys.key_encryptions
- sys.login_token
- sys.master_key_passwords
- sys.server_permissions
- sys.server_principals
- sys.server_role_members
- sys.sql_logins
- sys.user_token
