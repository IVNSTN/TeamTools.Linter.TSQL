
# ANSI_NULLS или QUOTED_IDENTIFIERS установлена внутри объекта

|||
|-|-|
| Id | **CD0895**
| Мнемо | CREATE_OPTIONS_INSIDE
| Серьёзность | ℹ Подсказка
| Категория | [НепрерывнаяПоставка](./Категория_НепрерывнаяПоставка.md)
| Исходный код | [CreateOptionsInsideRule.cs](../../../Rules/ContinuousDeployment/CreateOptionsInsideRule.cs)

## Причина

Правило срабатывает, если `ANSI_NULLS` или `QUOTED_IDENTIFIERS` установлена внутри объекта.
<p id="descr">Установите ANSI_NULLS или QUOTED_IDENTIFIERS перед инструкцией CREATE.</p>

## Примеры

Некорректно

```sql
CREATE PROCEDURE dbo.foo
AS
BEGIN
    SET QUOTED_IDENTIFIER, ANSI_NULLS ON;
END;
GO
```

Корректно

```sql
SET ANSI_NULLS, QUOTED_IDENTIFIER ON;
GO

CREATE PROCEDURE dbo.foo
AS
;
GO
```
