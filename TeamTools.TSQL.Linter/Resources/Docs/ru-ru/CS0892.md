

# Конвертация XML к строке с экранированием служебных символов

|||
|-|-|
| Id | **CS0892**
| Мнемо | CAST_XML_TO_STRING
| Серьёзность | ℹ Подсказка
| Категория | [СомнительноеКодирование](./Категория_СомнительноеКодирование.md)
| Исходный код | [CastXmlToStringRule.cs](../../../Rules/CodeSmell/CastXmlToStringRule.cs)

## Причина

Правило срабатывает, если XML конвертируется в строку с экранированием служебных символов.
<p id="descr">Используйте .value('.', 'NVARCHAR(MAX)') или STRING_AGG.</p>

## Примеры

Некорректно

```sql
SELECT STUFF(CAST((
                      SELECT ', ' + v.name
                      FROM (VALUES ('bonnie & clyde'), ('thelma & louise')) AS v (name)
                      FOR XML PATH(''), TYPE
                  ) AS NVARCHAR(MAX))
             , 1, 2, ''
            );
```

Корректно

```sql
SELECT STUFF((
                 SELECT ', ' + v.name
                 FROM (VALUES ('bonnie & clyde'), ('thelma & louise')) AS v (name)
                 FOR XML PATH(''), TYPE
             ).value('.', 'NVARCHAR(MAX)')
             , 1, 2, ''
            );
```
