

# Резкая смена уровня изоляции

|||
|-|-|
| Id | **CS0893**
| Мнемо | ISOLATION_CONTRADICTION
| Серьёзность | ℹ Подсказка
| Категория | [СомнительноеКодирование](./Категория_СомнительноеКодирование.md)
| Исходный код | [IsolationLevelContradictionRule.cs](../../../Rules/CodeSmell/IsolationLevelContradictionRule.cs)

## Причина

Правило срабатывает, если выставленный через hint уровень изоляции резко отличается от `SET TRANSACTION ISOLATION LEVEL`.
<p id="descr">Удалите резкое изменение уровня изоляции.</p>

## Примеры

Некорректно

```sql
SET TRANSACTION ISOLATION LEVEL REPEATABLE READ;

-- downgrade
SELECT * FROM tbl WITH (NOLOCK);
GO

SET TRANSACTION ISOLATION LEVEL READ COMMITTED;

-- upgrate
SELECT * FROM tbl WITH (SERIALIZABLE);
GO
```
