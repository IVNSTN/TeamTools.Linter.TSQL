
# Опции перечислены не в алфавитном порядке

|||
|-|-|
| Id | **CV0897**
| Мнемо | SET_OPTIONS_ASC_ORDER
| Серьёзность | ℹ Подсказка
| Категория | [СоглашенияПоКодированию](./Категория_СоглашенияПоКодированию.md)
| Исходный код | [SetOptionsInAscOrderRule.cs](../../../Rules/CodingConvention/SetOptionsInAscOrderRule.cs)

## Причина

Правило срабатывает, если опции перечислены не в алфавитном порядке.
<p id="descr">Укажите опции в алфавитном порядке.</p>

## Примеры

Некорректно

```sql
SET XACT_ABORT, ANSI_NULLS, NOCOUNT ON;
```

Корректно

```sql
SET ANSI_NULLS, NOCOUNT, XACT_ABORT ON;
```
