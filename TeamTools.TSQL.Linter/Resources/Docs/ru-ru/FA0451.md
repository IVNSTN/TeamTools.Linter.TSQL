
# Неразрешимая ссылка на определение окна

|||
|-|-|
| Id | **FA0451**
| Мнемо | UNRESOLVED_WINDOW_NAME
| Серьёзность | ⛔ Ошибка
| Категория | [Сбой](./Категория_Сбой.md)
| Исходный код | [UnresolvedWindowNameRule.cs](../../../Rules/Failure/UnresolvedWindowNameRule.cs)

## Причина

Правило срабатывает, если в `SELECT` указано имя окна, несуществующего в секции `WINDOW`.
<p id="descr">Исправьте имя окна.</p>

## Примеры

Некорректно

```sql
SELECT
    ProductID
    , SUM(OrderQty) OVER foo AS Total
FROM Sales.SalesOrderDetail
WINDOW bar AS(PARTITION BY SalesOrderID);
```

Корректно

```sql
SELECT
    ProductID
    , SUM(OrderQty) OVER bar AS Total
FROM Sales.SalesOrderDetail
WINDOW bar AS(PARTITION BY SalesOrderID);
```
