
# Переменная объявлена повторно

|||
|-|-|
| Id | **FA0457**
| Мнемо | VARIABLE_REDECLARED
| Серьёзность | ⛔ Ошибка
| Категория | [Сбой](./Категория_Сбой.md)
| Исходный код | [VariableRedeclaredRule.cs](../../../Rules/Failure/VariableRedeclaredRule.cs)

## Причина

Правило срабатывает, если переменная объявлена повторно.
<p id="descr">Удалите повторное объявление переменной.</p>

## Примеры

Некорректно

```sql
DECLARE @var INT = 1
-- ...
DECLARE @var DATE = GETDATE()
```
