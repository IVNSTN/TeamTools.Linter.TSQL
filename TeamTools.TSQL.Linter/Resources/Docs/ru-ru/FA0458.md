
# Неразрешимая ссылка на скалярную переменную

|||
|-|-|
| Id | **FA0458**
| Мнемо | UNRESOLVED_VARIABLED_NAME
| Серьёзность | ⛔ Ошибка
| Категория | [Сбой](./Категория_Сбой.md)
| Исходный код | [UnresolvedVariableReferenceRule.cs](../../../Rules/Failure/UnresolvedVariableReferenceRule.cs)

## Причина

Правило срабатывает, если скалярная переменная используется, но выше по коду не объявлена.
<p id="descr">Объявите скалярную переменную.</p>

## Примеры

Некорректно

```sql
SELECT name
FROM dbo.users
WHERE id = @user_id;
```

Корректно

```sql
DECLARE @user_id INT = 5;

SELECT name
FROM dbo.users
WHERE id = @user_id
```
