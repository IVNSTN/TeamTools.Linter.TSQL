
# Неразрешимая ссылка на табличную переменную

|||
|-|-|
| Id | **FA0459**
| Мнемо | UNRESOLVED_TABLE_VAR_NAME
| Серьёзность | ⛔ Ошибка
| Категория | [Сбой](./Категория_Сбой.md)
| Исходный код | [UnresolvedTableVariableReferenceRule.cs](../../../Rules/Failure/UnresolvedTableVariableReferenceRule.cs)

## Причина

Правило срабатывает, если табличная переменная используется, но выше по коду не объявлена.
<p id="descr">Объявите табличную переменную.</p>

## Примеры

Некорректно

```sql
SELECT usr.name
FROM dbo.users AS usr
INNER JOIN @ids AS ids
    ON ids.id = usr.id;
```

Корректно

```sql
DECLARE @ids TABLE (id INT PRIMARY KEY);
-- ...
SELECT usr.name
FROM dbo.users AS usr
INNER JOIN @ids AS ids
    ON ids.id = usr.id;
```
