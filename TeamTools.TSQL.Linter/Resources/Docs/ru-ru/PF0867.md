

# Столбцы внешнего ключа не индексированы

|||
|-|-|
| Id | **PF0867**
| Мнемо | INDEX_FK
| Серьёзность | ℹ Подсказка
| Категория | [Производительность](./Категория_Производительность.md)
| Исходный код | [ForeignKeyIndexRule.cs](../../../Rules/Performance/ForeignKeyIndexRule.cs)

## Причина

Правило срабатывает, если столбцы внешнего ключа не индексированы.
<p id="descr">Добавьте индекс по столбцам внешнего ключа.</p>

## Примеры

Некорректно

```sql
CREATE TABLE dbo.foo
(
    id           INT NOT NULL
    , group_id   INT NOT NULL
    , CONSTRAINT FK_group_id FOREIGN KEY (group_id) REFERENCES dbo.foo_groups (id)
);
GO
```

Корректно

```sql
CREATE TABLE dbo.foo
(
    id           INT NOT NULL
    , group_id   INT NOT NULL
    , CONSTRAINT FK_group_id FOREIGN KEY (group_id) REFERENCES dbo.foo_groups (id)
);
GO

CREATE NONCLUSTERED INDEX IX_group_id
    ON dbo.foo (group_id);
GO
```
