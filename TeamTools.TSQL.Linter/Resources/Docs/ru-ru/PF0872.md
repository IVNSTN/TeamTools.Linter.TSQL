

# Ручное принуждение к однопоточному плану выполнения

|||
|-|-|
| Id | **PF0872**
| Мнемо | SERIAL_PLAN_FORCED
| Серьёзность | ℹ Подсказка
| Категория | [Производительность](./Категория_Производительность.md)
| Исходный код | [SerialPlanForcedRule.cs](../../../Rules/Performance/SerialPlanForcedRule.cs)

## Причина

Правило срабатывает, если в запросе указаны `MAXDOP 1`, `REMOTE` соединение или `OUTPUT` без `INTO`.
<p id="descr">Удалите MAXDOP 1, REMOTE соединение или OUTPUT без INTO.</p>

## Примеры

Некорректно

```sql
INSERT INTO dbo.foo (title)
OUTPUT INSERTED.id
SELECT title
FROM dbo.bar;
GO

SELECT f.title
FROM dbo.foo AS f
INNER REMOTE JOIN dbo.bar AS b
    ON f.id = b.parent_id
OPTION (MAXDOP 1);
GO
```

Корректно

```sql
INSERT dbo.foo (title)
OUTPUT INSERTED.id
INTO @ids
SELECT title
FROM dbo.bar;
GO

SELECT f.title
FROM dbo.foo AS f
INNER JOIN dbo.bar AS b
    ON f.id = b.parent_id;
GO
```
