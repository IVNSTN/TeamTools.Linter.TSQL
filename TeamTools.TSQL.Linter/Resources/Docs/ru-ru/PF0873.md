

# Принуждение к однопоточному плану выполнения из-за модификации табличной переменной

|||
|-|-|
| Id | **PF0873**
| Мнемо | SERIAL_PLAN_FORCED_TABLE_VAR
| Серьёзность | ℹ Подсказка
| Категория | [Производительность](./Категория_Производительность.md)
| Исходный код | [SerialPlanForcedByTableVariableRule.cs](../../../Rules/Performance/SerialPlanForcedByTableVariableRule.cs)

## Причина

Правило срабатывает, если в запросе модифицируется табличная переменная.
<p id="descr">Замените табличную переменную на временную таблицу.</p>

## Примеры

Некорректно

```sql
INSERT INTO @var_table(title)
SELECT title
FROM bar;
```

Корректно

```sql
INSERT INTO #temp_table(title)
SELECT title
FROM bar;
```
