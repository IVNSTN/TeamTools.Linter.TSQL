

# Принуждение к однопоточному фрагменту плана выполнения явной инструкцией

|||
|-|-|
| Id | **PF0874**
| Мнемо | SERIAL_PLAN_ZONE_FORCED
| Серьёзность | ℹ Подсказка
| Категория | [Производительность](./Категория_Производительность.md)
| Исходный код | [SerialPlanZoneForcedRule.cs](../../../Rules/Performance/SerialPlanZoneForcedRule.cs)

## Причина

Правило срабатывает, если в запросе используются инструкции приводящие к однопоточному фрагменту плана выполнения.
<p id="descr">Измените логику или удалите инструкции приводящие к однопоточному фрагменту плана выполнения.</p>

## Примеры

Некорректно

```sql
INSERT INTO @var_table(title)
SELECT title
FROM bar;
```

Корректно

```sql
INSERT INTO #temp_table(title)
SELECT title
FROM bar;
```

## Подсказки

💡 Правило реагирует на:

- LOOP JOIN
- TOP
- ROW_NUMBER
- RANK
- STRING_AGG
- MAXRECURSION
