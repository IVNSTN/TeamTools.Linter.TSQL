

# Принуждение к однопользовательскому доступу явной инструкцией

|||
|-|-|
| Id | **PF0878**
| Мнемо | SINGLE_USER_MODE_ZONE_FORCED
| Серьёзность | ℹ Подсказка
| Категория | [Производительность](./Категория_Производительность.md)
| Исходный код | [SingleUserModeZoneForcedRule.cs](../../../Rules/Performance/SingleUserModeZoneForcedRule.cs)

## Причина

Правило срабатывает, если в коде используется `sp_getapplock` или хинты: `TABLOCKX`, `TABLOCK+XLOCK`, `TABLOCK+UPDLOCK`.
<p id="descr">Удалите sp_getapplock или хинты: TABLOCKX, TABLOCK+XLOCK, TABLOCK+UPDLOCK.</p>

## Примеры

Некорректно

```sql
SELECT id
FROM dbo.foo WITH (TABLOCKX);

DELETE dbo.foo
WHERE id < 5
OPTION (TABLE HINT(TABLOCK, UPDLOCK));
```

Корректно

```sql
SELECT id
FROM dbo.foo;

DELETE dbo.foo
WHERE id < 5;
```
