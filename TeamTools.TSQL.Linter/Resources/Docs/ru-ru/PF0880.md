

# JOIN не содержит явного фильтра по строгому равенству

|||
|-|-|
| Id | **PF0880**
| Мнемо | NO_EQUALITY_FILTER_JOIN
| Серьёзность | ℹ Подсказка
| Категория | [Производительность](./Категория_Производительность.md)
| Исходный код | [NoEqualityFilterInJoinRule.cs](../../../Rules/Performance/NoEqualityFilterInJoinRule.cs)

## Причина

Правило срабатывает, если `JOIN` не содержит явного фильтра по строгому равенству.
<p id="descr">Добавьте фильтр по строгому равенству.</p>

## Примеры

Некорректно

```sql
SELECT f.id
FROM dbo.foo AS f
INNER JOIN dbo.bar AS b
    ON f.date > y.date;
```

Корректно

```sql
SELECT f.id
FROM dbo.foo AS f
INNER JOIN dbo.bar AS b
    ON f.date = y.date;
```
