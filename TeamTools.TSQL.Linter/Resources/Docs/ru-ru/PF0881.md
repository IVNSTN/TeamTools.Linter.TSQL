

# WHERE не содержит явного фильтра по строгому равенству

|||
|-|-|
| Id | **PF0881**
| Мнемо | NO_EQUALITY_FILTER_WHERE
| Серьёзность | ℹ Подсказка
| Категория | [Производительность](./Категория_Производительность.md)
| Исходный код | [NoEqualityFilterInWhereRule.cs](../../../Rules/Performance/NoEqualityFilterInWhereRule.cs)

## Причина

Правило срабатывает, если `WHERE` не содержит явного фильтра по строгому равенству.
<p id="descr">Добавьте фильтр по строгому равенству.</p>

## Примеры

Некорректно

```sql
SELECT f.id
FROM dbo.foo AS f
INNER JOIN dbo.bar AS b
    ON f.date = y.date
WHERE f.date > @year_begin;
```

Корректно

```sql
SELECT f.id
FROM dbo.foo AS f
INNER JOIN dbo.bar AS b
    ON f.date = y.date
WHERE f.date_year = @year;
```
