
# Избыточное определение окна

|||
|-|-|
| Id | **RD0452**
| Мнемо | UNUSED_WINDOW_CLAUSE
| Серьёзность | ⚠ Предупреждение
| Категория | [Избыточность](./Категория_Избыточность.md)
| Исходный код | [UnusedWindowClauseRule.cs](../../../Rules/Redundancy/UnusedWindowClauseRule.cs)

## Причина

Правило срабатывает, если в секции `WINDOW` объявлено окно, но оно ни разу не использовано.
<p id="descr">Удалите избыточное окно.</p>

## Примеры

Некорректно

```sql
SELECT
    ProductID
FROM Sales.SalesOrderDetail
WINDOW bar AS(PARTITION BY SalesOrderID);
```

Корректно

```sql
SELECT
    ProductID
FROM Sales.SalesOrderDetail;
```
