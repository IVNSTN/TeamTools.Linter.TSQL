

# Избыточное указание MAXRECURSION в запросе без рекурсивных CTE

|||
|-|-|
| Id | **RD0882**
| Мнемо | REDUNDANT_MAX_RECURSION
| Серьёзность | ⚠ Предупреждение
| Категория | [Избыточность](./Категория_Избыточность.md)
| Исходный код | [RedundantMaxRecursionRule.cs](../../../Rules/Redundancy/RedundantMaxRecursionRule.cs)

## Причина

Правило срабатывает, если в запросе без рекурсивных `CTE` указана опция `MAXRECURSION`.
<p id="descr">Удалите MAXRECURSION.</p>

## Примеры

Некорректно

```sql
WITH cte AS (SELECT id, parent_id FROM foo WHERE parent_id IS NULL)
SELECT * FROM cte
OPTION (MAXRECURSION 10);
```
