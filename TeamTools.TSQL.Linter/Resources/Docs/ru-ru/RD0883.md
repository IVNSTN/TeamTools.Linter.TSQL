

# Избыточное вычисление ISNULL в неравенстве

|||
|-|-|
| Id | **RD0883**
| Мнемо | REDUNDANT_ISNULL_NOT_EQUALS
| Серьёзность | ℹ Подсказка
| Категория | [Избыточность](./Категория_Избыточность.md)
| Исходный код | [RedundantIsNullForInequalityRule.cs](../../../Rules/Redundancy/RedundantIsNullForInequalityRule.cs)

## Причина

Правило срабатывает, если при возврате `replacement_value` в `ISNULL` выражение теряет смысл.
<p id="descr">Удалите избыточное ISNULL.</p>

## Примеры

Некорректно

```sql
SELECT * 
FROM foo 
WHERE foo.col <> ISNULL(@arg, foo.col);
```

Корректно

```sql
SELECT * 
FROM foo 
WHERE foo.col <> @arg;
```
