
# Выражения можно объединить в один SET

|||
|-|-|
| Id | **SI0896**
| Мнемо | MULTIPLE_SET_INTO_ONE
| Серьёзность | ℹ Подсказка
| Категория | [Упрощение](./Категория_Упрощение.md)
| Исходный код | [MultipleSetOptionIntoOneRule.cs](../../../Rules/Simplification/MultipleSetOptionIntoOneRule.cs)

## Причина

Правило срабатывает, если выражения SET заданы отдельно.
<p id="descr">Объедините выражения SET.</p>

## Примеры

Некорректно

```sql
SET NOCOUNT ON;
SET XACT_ABORT ON;
```

Корректно

```sql
SET NOCOUNT, XACT_ABORT ON;
```
