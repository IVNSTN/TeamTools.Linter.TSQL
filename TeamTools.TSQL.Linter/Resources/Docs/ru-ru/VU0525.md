

# Попытка вернуть секрет

|||
|-|-|
| Id | **VU0525**
| Мнемо | OUTPUT_SECRET
| Серьёзность | ℹ Подсказка
| Категория | [Уязвимость](./Категория_Уязвимость.md)
| Исходный код | [OutputSecretRule.cs](../../../Rules/Vulnerability/OutputSecretRule.cs)

## Причина

Правило срабатывает, если через `SELECT` или `OUTPUT` параметры осуществляется попытка вернуть секрет.
<p id="descr">Удалите код возвращающий секрет.</p>

## Примеры

Некорректно

```sql
SELECT password FROM dbo.users;
```

## Подсказки

💡 Правило проверяет столбцы и параметры с именами:

- password
- pass_word
- pwd
- pswd
- secret
