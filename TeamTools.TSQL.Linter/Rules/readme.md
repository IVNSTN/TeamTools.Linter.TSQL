
# Особенности написания правил

Правила должны быть **immutable**! Т.е. анализ любого скрипта не должен оставлять в правиле никаких следов, не должен иметь влияния на анализ каких-то других скриптов.
Таким образом правило может хранить только общие данные, относящиеся к анализу любых скриптов. Например, перечень названий ф-й, на которые оно реагирует.

Нужно в том числе для того чтобы инстанцировать правила один раз и выполнить на множестве файлов. В том числе в параллельных тредах.

## Размещение файлов

Для каждого правила в самом начале должна быть определена его категория, например, Naming - для правил, касающихся именования SQL-объектов.

**Файлы реализации правила** должны находиться в поддиректории `../Rules` для этой категории (например, [Rules/Naming](../Rules/Naming/)).
**Юнит-тесты правила** должны располагаться в поддиректории `../../TeamTools.TSQL.LinterTests/UnitTests` для этой категории (например, [UnitTests/Naming](../../TeamTools.TSQL.LinterTests/UnitTests/Naming/)) и далее в папке с именем, совпадающим с именем класса правила.

## Описание правила

Для каждого нового правила необходимо:

- выбрать буквенный префикс, характерный для выбранной _категории правила_ (например, "NM" для правил именования, категория Naming)
- выделить глобально уникальный _среди всех правил_ четырёхзначный числовой номер, ещё не занятый другим правилом (например, "0579")
- выбрать глобально уникальный мнемокод, раскрывающий смысл правила, но всё же краткий (например, "TABLE_NAME_IS_UNIQUE")
- добавить строку в [DefaultConfig.json](../DefaultConfig.json)
  - в блок с правилами выбранной категории (например, где собраны правила с префиксом "NM")
  - на позицию в соответствии с сортировкой номеров по возрастанию
  - указать полный идентификатор с мнемокодом (например, "NM0579:TABLE_NAME_IS_UNIQUE")
  - указать подходящий уровень severity: "error", "warning" или "hint"
- добавить строку с сообщением о нарушении правила:
  - в [ViolationMessages.json](../Resources/ViolationMessages.json) _in english_
  - в [ViolationMessages.ru-ru.json](../Resources/ViolationMessages.ru-ru.json) _на русском_
